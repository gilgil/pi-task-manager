# task.ts

## Summary

The source defines a TypeScript interface for a Task object that was ported from a Python Task dataclass. The interface includes core task properties such as id, text, and completed status, along with optional metadata fields for categorization and tracking.

The Task interface supports rich task management features including optional emoji, category, priority, project, context, tags, due date, creation date, modification date, and indentation level. This structure enables flexible task organization with both required fields for basic task functionality and optional fields for advanced categorization and metadata.

## Key Takeaways

- Task interface is ported from a Python Task dataclass to TypeScript
- Core required fields include id, text, completed, and indent
- Optional metadata fields support rich task categorization (emoji, category, priority, project, context, tags)
- Temporal tracking fields include due, created, and modified dates
