# tasks_emojis_format.md

## Summary

This source demonstrates the emoji format syntax supported by the Tasks plugin for representing various task metadata fields. It provides examples of how emojis are used as signifiers for dates, priorities, recurrence, on-completion actions, and task dependencies.

The documentation covers six categories of emoji-based task formatting: dates (created, scheduled, start, due, done, and cancelled), priority levels (from lowest to highest), recurrence patterns, on-completion behavior (keep or delete), and task dependencies using unique identifiers.

## Key Takeaways

- The Tasks plugin supports emoji signifiers to represent task metadata fields
- Date types use distinct emojis: ➕ created, ⏳ scheduled, 🛫 start, 📅 due, ✅ done, ❌ cancelled
- Priority levels range from lowest (⏬) to highest (🔺) using arrow emojis
- Recurrence is marked with the 🔁 emoji followed by the recurrence pattern
- On-completion actions use 🏁 with 'keep' or 'delete' to control task behavior when completed
- Dependencies use 🆔 for the task ID and ⛔ for blocking dependencies with referenced task IDs
